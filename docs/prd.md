# PRD — IR Copier

## 目标

在 M5StickS3 上实现一个极简的红外遥控器复制工具，功能对标 Bruce 固件的 IR Read/Replay，但 UI 更干净、只做 Copy 和 Replay 两件事、去除噪声误触发。

## 用户

拥有 M5StickS3 和电视遥控器的个人用户。希望用一个袖珍设备替代或备份电视遥控器。

## 核心需求

1. **Copy**：将电视遥控器对准 StickS3，按下遥控器按键，设备抓取 NEC 红外码并存储。需要去抖/校验，避免环境红外噪声导致误抓（Bruce 固件的已知问题）。
2. **Replay**：从存储中读出已抓的红外码，通过 IR LED 发射。屏幕显示已存储的码列表，选择后发射。
3. **持久化**：抓到的码断电不丢失（存入 NVS/flash）。
4. **极简 UI**：开机即菜单，Copy / Replay 两个选项，侧边按钮导航，正面 Select 确认。

## 成功标准

- 能成功抓取至少 3 种电视遥控器按键的 NEC 码
- 抓到的码能成功回放并控制电视
- 无遥控器信号时不会误抓噪声
- 断电后码仍在
- 从开机到完成一次 Copy 操作 < 10 秒

## 非目标

- 不支持空调遥控器（长协议）
- 不做 WiFi/蓝牙/OTA
- 不做手机 App
- 不做通用红外码库下载
